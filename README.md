# 🛒 VianaHub - E-commerce Intelligence

> **Plataforma Full-Stack de E-commerce focada no setor alimentício, com gestão dinâmica e interface premium.**

O **VianaHub** é uma solução completa de vendas online, entrega e pagamentos, projetada para oferecer uma experiência de usuário fluida e um painel administrativo robusto para lojistas. O projeto se destaca pelo uso de tecnologias de ponta e um design moderno que segue as tendências da indústria.

---

## 💎 Diferenciais do Projeto

### 🎨 Design & Experience (Glassmorphism)
*   **Interface Glass Theme:** Layout moderno utilizando a estética *Glassmorphism* (efeitos de transparência e desfoque), amplamente adotada por grandes marcas do setor para transmitir sofisticação.
*   **Customização por Lojista:** Motor de temas que permite ao administrador personalizar a identidade visual da loja em tempo real.
*   **Hubs Distintos:** Ecossistema dividido em áreas exclusivas para o **Lojista** (gestão) e para o **Cliente** (experiência de compra).

### ⚙️ Funcionalidades Core
*   **Segurança Avançada:** Sistema de autenticação robusto integrado via Google OAuth e E-mail através do Supabase.
*   **Pagamentos Online:** Integração total com o gateway do **Mercado Pago**, garantindo transações seguras e suporte a diversos métodos de pagamento.
*   **Real-time Intelligence:** Notificações instantâneas de pedidos e atualizações de status utilizando Webhooks e banco de dados em tempo real.
*   **Gestão de Logística:** Fluxo completo desde a escolha do alimento até a entrega final ao cliente.

---

## 🚀 Stack Tecnológica

*   **Frontend:** React.js / Next.js
*   **Estilização:** CSS-in-JS / Tailwind CSS (Focado em Glass Design)
*   **Backend & Database:** Supabase (PostgreSQL, Real-time e Auth)
*   **Pagamentos:** API Mercado Pago
*   **Qualidade:** Implementações de testes automatizados para garantir a estabilidade do fluxo de checkout.

---

## 🏗️ Estrutura do Sistema

O projeto foi arquitetado para ser escalável e modular, separando as responsabilidades em:

1.  **Storefront:** A vitrine otimizada para conversão e performance.
2.  **Merchant Hub:** O painel de controle do lojista para gestão de estoque e temas.
3.  **Integration Layer:** Camada de serviços que conecta o banco de dados aos gateways de pagamento e autenticação.
